Entry for [The Agent's Uh-Oh](https://make.fun/c/u-danu-the-agent-s-uh-oh-4c0911e4)
bounty on [make.fun](https://make.fun): one word, at most 99 characters,
that an agent says when it has no idea what to do.

## The word

> recalculating

The sound of an agent caught mid-task, stalling out loud while it quietly
re-plans — the GPS voice of a machine that just realised it is lost.

## How it works

`main.py` writes the word to `/output/entry.txt`:

```sh
python3 main.py
```

The file holds exactly the 13-character word above — no trailing newline —
so it passes the gate (UTF-8 text, 1–99 characters) and stays as small as
possible for the size tie-break.
